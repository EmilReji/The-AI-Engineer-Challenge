# Frontend Verification

Check that the frontend:

- has clear visuals and sufficient contrast;
- provides a pleasant user experience with containers that fit their content;
- uses password-style inputs for sensitive information;
- uses Next.js and supports Vercel deployment;
- can be tested locally;
- documents how to run the UI.
